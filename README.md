# Kids English Word Trainer

小学生向け英単語学習アプリのMVPです。日本語UIで、毎日/毎週の学習サイクル、学年・カテゴリ別の単語生成、選択式テスト、30日間の再出題停止、JSON/Excelインポートに対応します。

## 使い方

`index.html` をブラウザで開くと起動します。データはブラウザの `localStorage` に保存されます。

Excelインポートはブラウザ上でSheetJS CDNを読み込みます。ネットワークがない環境ではJSONインポートと手動追加を使えます。

## 開発チェック

```bash
npm test
npm run check
```

## 主な実装範囲

- ホーム、学習、テスト、結果、設定、単語管理画面
- 学年以下の単語を対象にする出題制御
- カテゴリ指定、複数カテゴリ、ランダムカテゴリ
- 毎週モード: 月曜生成、土日テスト
- 毎日モード: 当日生成、翌日テスト
- 正答率による合格判定
- 正解単語の30日クールダウン
- 不正解単語の再出題候補化
- JSON / Excelインポートのバリデーション
